# Open Source Governance

inFlow for Stellar is an open-source project maintained by the InflowFinance community.

---

## 👥 Roles & Responsibilities

### Contributors
Anyone who files issues, submits code PRs, improves documentation, or participates in code reviews.

### Maintainers
Active project contributors who demonstrate consistent technical quality, community stewardship, and domain knowledge. Maintainers have commit access and review pull requests.

### Core Maintainers
Lead architects responsible for protocol security, smart contract deployments, release tagging, and overall technical vision.

---

## ⚖️ Decision-Making Process

- **Routine Changes:** Reviewed and merged by maintainers via GitHub Pull Requests.
- **Architectural & Security Changes:** Discussed publicly in GitHub Discussions/Issues prior to implementation.
- **Protocol Upgrades:** Require consensus among Core Maintainers and validation against test suites on Stellar Testnet.
