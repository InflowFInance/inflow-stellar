# Governance

inFlow for Stellar is maintained by the inflow-protocol community.

## Roles

**Contributors** — Submit PRs, file issues, improve docs.
**Maintainers** — Review PRs, triage issues, guide direction. Have merge rights.
**Core Maintainers** — Oversee protocol design, security, release planning.

## Decision Making

- Routine changes: PR review by maintainers
- Larger changes (contract interface, security model, breaking changes): discussed in a GitHub Issue before implementation

## Release Management

- Releases tagged and documented in CHANGELOG.md
- Smart contract changes require additional review

## Conflict Resolution

Handled constructively and publicly. Core maintainers make final decisions.
