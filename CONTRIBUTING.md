# Contributing

Thanks for your interest in contributing to inFlow for Stellar!

## Code of Conduct

This project adheres to a [Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

## How to Contribute

### Reporting Bugs

- Use the GitHub issue tracker
- Describe the bug, expected behavior, and actual behavior
- Include reproduction steps and environment details

### Suggesting Features

- Open a GitHub issue with the `enhancement` label
- Describe the use case and proposed solution

### Pull Requests

1. Fork the repo and create a new branch from `main`
2. Make your changes with clear, descriptive commit messages
3. Ensure all tests pass and linters are clean
4. Update documentation if needed
5. Submit a PR — maintainers will review within 7 days

## Development Setup

See the [README](README.md) for local development instructions.

## Commit Guidelines

- Use conventional commits: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `chore:`
- Keep commits atomic — one logical change per commit
- Write meaningful commit messages — no spam
