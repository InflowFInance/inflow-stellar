# Security Policy

## 🔒 Reporting Vulnerabilities

**Do not file public GitHub issues for security vulnerabilities.**

If you discover a potential vulnerability in the Soroban contract, SDK, or Worker relay, please report it via GitHub Private Vulnerability Reporting or email:

**`security@inflow.finance`**

Include:
1. Detailed description of the vulnerability
2. Steps to reproduce or proof-of-concept code
3. Potential impact assessment

We aim to respond to reports within 48 hours and resolve critical issues within 14 days.

---

## 🛡️ Smart Contract Disclaimer

The inFlow Soroban smart contract is open source. While unit test coverage is comprehensive, the contract has not yet undergone a third-party security audit. Exercise caution when deploying significant funds to production.
