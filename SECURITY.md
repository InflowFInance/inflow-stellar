# Security Policy

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Please use GitHub's private vulnerability reporting feature, or email
security@inflow-stellar.dev.

Include the following information:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Optional: suggested fix

We aim to respond within 72 hours and resolve critical issues within 14 days.

## Smart Contract Security

The inFlow Soroban contract is currently unaudited.
Do not use with significant funds until a formal audit is complete.

## Scope

In scope: Soroban contract, SDK, Cloudflare Worker backend
Out of scope: Third-party dependencies, Stellar protocol itself
